# Week03 — Roboflow 음료 캔 라벨링 실습

강의계획서의 3주차 목표인 **인공지능 데이터 확보**와 **Roboflow 라벨링**을 위한 실습 자료입니다.

## 학습 목표
- 다양한 경로로 이미지 데이터를 확보한다.
- 이미지 데이터 저작권과 사용 조건을 확인한다.
- Roboflow 프로젝트를 생성한다.
- 음료 캔 이미지를 Bounding Box로 라벨링한다.
- 클래스별 폴더 저장 방식과 객체탐지 라벨 방식의 차이를 이해한다.
- 데이터셋 버전을 생성하고 YOLOv8 형식으로 내보낸다.
- Colab에서 Roboflow 데이터셋을 내려받아 구조를 확인한다.

## 권장 클래스 예시
- coke
- sprite
- fanta

## 수업 흐름
1. 이미지 데이터 확보
2. 데이터 정리와 저작권 설명
3. Roboflow 프로젝트 생성
4. 이미지 업로드
5. Bounding Box 라벨링
6. Dataset Version 생성
7. YOLOv8 Export
8. Colab 다운로드 및 데이터 구조 확인
9. 선택: YOLOv8n 10 epoch 학습
